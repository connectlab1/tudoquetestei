Decidi testar se é realmente fácil colocar um site no ar do zero usando apenas o GitHub Pages e a engine do Jekyll.

### Vantagens que notei:
* **Gratuito:** Zero custo de infraestrutura.
* **Leveza:** Carregamento praticamente instantâneo das páginas.
* **Praticidade:** Escrever tudo em formato Markdown economiza muito tempo.

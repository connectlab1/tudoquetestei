Decidi testar se é realmente fácil colocar um site no ar do zero usando apenas o GitHub Pages e a engine do Jekyll.

### O Experimento
A ideia era subir uma estrutura de blog completa sem precisar pagar por hospedagem ou instalar um banco de dados como o WordPress.

### Vantagens que notei:
* **Gratuito:** Zero custo de infraestrutura.
* **Leveza:** Carregamento praticamente instantâneo das páginas.
* **Praticidade:** Escrever tudo em formato Markdown economiza muito tempo.

### PONTOS NEGATIVOS:
* Requer um pequeno tempo de adaptação com a sintaxe dos arquivos.

---
**Veredito final:** Aprovado! Vale muito a pena para blogs pessoais e documentações.
